ตั้งใน Vercel

เพื่อให้สมาชิกทุกคนส่งเข้าห้อง Discord ได้อย่างปลอดภัย ให้แอดมินตั้งค่า Webhook เป็น Environment Variable ใน Vercel หนึ่งครั้ง

บ้านนี้ใช้ชื่อตัวแปร DISCORD_WEBHOOK_1
เปิด Vercel → Project Settings → Environment Variables แล้วเพิ่มตัวแปรนี้และวาง Webhook เป็นค่า จากนั้น Redeploy
วิธีตั้งค่าแบบสั้น
  1. ใน Vercel เปิดโปรเจกต์เว็บนี้ → Settings → Environment Variables
  2. เพิ่มชื่อตัวแปรที่แสดงด้านบน แล้ววาง URL ของ Discord Webhook เป็นค่า
  3. เลือก Production แล้วกด Save
  4. ไปที่ Deployments แล้วกด Redeploy เวอร์ชันล่าสุด
  5. บ้านอื่นใช้ชื่อ DISCORD_WEBHOOK_2 ถึง DISCORD_WEBHOOK_6
